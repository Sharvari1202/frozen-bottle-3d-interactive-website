# 🍓 FROZEN BOTTLE – 3D Interactive Beverage Website

A premium, visually immersive beverage website featuring interactive 3D-style bottle showcases, smooth animations, creative product presentations, and a modern user interface.

FROZEN BOTTLE is designed to deliver an engaging digital product experience through creative visuals, animated bottle interactions, flavour exploration, and dynamic scrolling effects.
